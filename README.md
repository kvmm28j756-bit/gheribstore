# gheribstore

موقع ثابت ومتجاوب لعرض تريكوات gheribstore، باللونين الأسود والأبيض، مع المقاسات S وM وL والسعر 2300 دج.

## معاينة محلية

افتح `index.html` مباشرة في المتصفح. صور المنتج موجودة في `images/` بصيغة SVG، ولا يحتاج الموقع إلى تثبيت أو بناء.

## النشر على Netlify

ارفع مجلد المشروع إلى Netlify أو اربط هذا المستودع به. الموقع static ولا يحتاج build command؛ مجلد النشر هو جذر المشروع (`.`).

## مهم

نموذج الطلب يعرض رسالة نجاح للزبون فقط في هذه النسخة. لا تُحفظ الطلبات ولا تُرسل إلى تيليغرام حتى تضيف الربط لاحقًا.
